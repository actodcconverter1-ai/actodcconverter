# Category and language review

All seven existing category routes are retained and indexable: `measurement-guides`, `worked-examples`, `component-behavior`, `capacitor-filtering`, `component-models`, `calculator-guides`, and `voltage-measurement`.

Decision per category: **retain and improve the introduction**, rather than noindex. Each already has original multi-paragraph learning guidance, an ordered reading path and matching article cards. The first category-specific learning paragraph is now placed before the reading-path heading. Together with the existing category introduction this creates an approximately 90–140-word introductory area; the remaining guidance stays below the reading path. Existing specific metadata is retained. These are not empty tag archives; no filler or new category URL is added.

All 18 language versions remain supported. The build/locale audits check self-canonicals, reciprocal hreflang/x-default, indexability and sitemap coverage. The 17 translated versions have legacy locally machine-translated articles and no documented native technical sign-off; none is certified as fully reviewed here. See `seo-owner-input.md` for the recommendation and required review. Thinness cannot be inferred from an absence of GSC impressions alone. No language is removed or silently noindexed.
